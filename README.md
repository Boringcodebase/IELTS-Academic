# IELTS Academic Study Vault

Personal study notes for preparing for the **IELTS Academic** test.

The vault brings together grammar, vocabulary, sentence-building practice, and
strategies for all four skills: listening, reading, writing, and speaking.

## Start here

Open [`00_Dashboard/Index_Dashboard.md`](00_Dashboard/Index_Dashboard.md) for
the main roadmap, then study the topics that match your current goals.

## Main sections

- `01_Foundations_and_Mechanics` — sentence structure and core grammar
- `02_Parts_of_Speech` — nouns, verbs, modifiers, and other word classes
- `03_Core_Tenses` — tense usage and listening resources
- `04_Voice_and_Modals` — voice, modals, and reported speech
- `05_Advanced_Structures` — conditionals, inversion, and cleft sentences
- `06_Cohesion_and_Coherence` — organizing and connecting ideas
- `07_Error_Correction` — common mistakes and correction practice
- `08_IELTS_Application` — strategies for each IELTS skill
- `09_Punctuation_and_Capitalization` — punctuation and spelling rules
- `10_ Vocab Lexical_Resource` — vocabulary, collocations, and paraphrasing
- `11_Idiomatic_Language` — idioms and natural expressions
- `13_Sentence_Building_Workshop` — guided sentence practice
- `App_*` — additional writing, speaking, listening, and reference materials
